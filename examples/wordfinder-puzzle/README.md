# Word Finder Puzzle

Standalone mini-game exported by X Mini-Game Studio.

Deploy this folder to a public static HTTPS host. Keep index.html and poster.png together. Update metadata image URLs to the actual public poster URL.

Personal bests use local browser storage on each device; there is no server database or global leaderboard. Sharing a result shares score text and a challenge URL.

Use a regular website link preview to open the hosted game. Do not embed the game as an X Player Card. Test the link preview in current X clients before promotion.
