# Start here in Codex

1. Open existing folder `~/Developer/WotaGame` as the Codex workspace.
2. Read `AGENTS.md` and `CODEX_HANDOFF.md`.
3. Run `bash scripts/codex-preflight.sh`.
4. Follow `docs/codex/KNOWN_STATE_AND_FIRST_TASK.md`.
5. Paste `CODEX_START_PROMPT.md` into your Codex session.

The handoff ZIP contains instructions/docs, not a replacement app. Keep `.env.local`, `.vercel/` and secret values private.
